\begin{abstract}
\noindent
This whitepaper describes the \textbf{complete architecture} of the \texttt{libp2p-raft} crate:
how a Raft state machine is embedded into rust-libp2p through the \texttt{NetworkBehaviour} /
\texttt{ConnectionHandler} model, module boundaries, runtime data structures, event contracts,
election/replication/inbound-outbound RPC flows, the wire specification, the failure matrix,
storage and snapshots, and the event-driven execution model. The content tracks the source in
\texttt{src/behaviour.rs}, \texttt{src/handler.rs}, \texttt{src/raft/engine.rs},
\texttt{src/protocol/} and \texttt{src/storage/}.
\end{abstract}

\noindent\textbf{Keywords:} Raft, libp2p, Swarm, NetworkBehaviour, ConnectionHandler,
unary RPC, Yamux, hexagonal architecture, correlation ID, snapshot.
